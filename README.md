# McDermot Avenue Baptist Church Website

To get started, clone the repository, install Node with [`nvm`](https://github.com/nvm-sh/nvm), get `pnpm` with `corepack`, then install the dependencies:

```console
$ nvm install
$ npm install --global corepack@latest
$ corepack enable
$ pnpm install
```

Now you're good to go. Run the project locally:

```console
$ pnpm dev
# visit localhost:5173
```

Or, build the project for production and preview it:

```console
$ pnpm build
$ pnpm preview
# visit localhost:4173
```
